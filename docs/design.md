# Kmoe Sync 产品与界面设计

自托管在 NAS 上的 Kmoe 漫画同步服务：登录一次 Kmoe，订阅追更，按卷挑选下载，
文件落到 NAS 本地目录或 WebDAV 书库。视觉与交互采用「墨与纸」设计。

## 用户与场景

- **NAS 用户、电子书阅读者**：用 Kindle / Boox / KOReader / 平板读 EPUB、MOBI，书库放在 NAS 或 WebDAV。
- 同时可能在用浏览器扩展：两者使用**同一套命名规则**，写进同一个书库时能互相识别已下载的章节。

核心任务（按频率）：
1. 追更：连载漫画有新卷 / 新话时自动下载到书库，并收到通知。
2. 补书：找到一部漫画，勾选需要的卷，立即下载（不必先订阅）。
3. 维护书库：知道哪些已下载、哪些缺失、哪些下载失败，一键补齐或重试。
4. 无人值守：Kmoe 登录失效、额度不足、服务器连不上时，暂停并通知，而不是默默失败。

## 信息架构

```
书架（首页）   已订阅 / 已下载 / 已导入的漫画，状态概览，最近动态
发现           搜索 Kmoe · 粘贴链接 · Bangumi 书单
下载           队列：进行中 / 等待 / 失败 / 已完成
书库整理       书库里的系列文件夹 ↔ Kmoe 漫画 ↔ Bangumi 条目 / Komga 系列：扫描导入、确认匹配、同步元数据
漫画页         /comics/:key   章节网格 + 下载 + 订阅设置 + 对应文件夹 + 元数据
设置           基本：Kmoe 账号 · 存储位置 · 下载与更新 · 通知
               集成：Komga 元数据 · Bangumi 书单 · AI · API 与 MCP
               系统：网络代理 · 安全 · 关于
```

导航：桌面左侧栏（名称「Kmoe Sync」纯文字，不放 logo），五个入口（书架 / 发现 / 下载 / 书库整理 / 设置）+ 底部状态
（下载队列一行、固定高度；其下是 Kmoe 连接与额度）。「书库」只指存放漫画的地方（本地目录或 WebDAV），整理它的页面叫「书库整理」。
手机：顶部栏 + 底部标签栏（同样五个入口），漫画页全屏。AI 助手是右下角的悬浮按钮（漫画页在标题下方「问 AI」）。

书库的单位是「系列文件夹」（直接包含电子书的文件夹，与 Komga 的系列一一对应）。文件从不移动或改名；
导入只是把文件夹关联到 Kmoe 漫画，已有的卷由书库检查识别为已下载。元数据按文件夹写入 Komga。

## 页面

### 首次使用
1. **创建管理员密码**（只有一个管理员）。
2. 进入书架空状态，引导三步：登录 Kmoe → 添加存储位置（默认已有「本地书库」）→ 去发现页找漫画。
   浏览器扩展用户可直接「导入扩展配置」，WebDAV 服务器与命名规则一次迁移。

### 书架（首页）
- 顶部状态条：队列（下载中 n · 等待 n · 速度）、Kmoe 额度剩余、下次自动检查时间、「立即检查全部」。
  三格等高、一行：宽屏每格是 图标 · 名称/数值 · 靠右的细节（速度、额度条、检查按钮），窄格只留名称和数值；
  手机上「立即检查」在顶栏。
  队列被暂停时（手动 / 额度不足 / 登录失效）显示醒目但克制的提示条与恢复操作。
- 封面墙：每部漫画一张卡片——封面、标题、作者、进度（已下载 12 / 13 卷）、状态标记
  （追更中 · 已暂停 · 有新章节 · 有失败），「新」章节数徽标。
- 筛选：全部 / 追更中 / 有更新 / 有失败；书架内搜索。
- 最近动态：发现新章节、下载完成 / 失败、登录失效等，可点进对应漫画。

### 发现
- 大搜索框：输入关键词，或粘贴任意镜像 / 手机版的 Kmoe 链接直接打开漫画页。
- 结果：封面网格（封面、标题、作者、最新、已在书架标记），分页。
- Bangumi 片单（Tab）：同步到的「想看 / 在看…」条目，状态为 待匹配 / 已匹配 / 已忽略；
  「在 Kmoe 查找」→ 搜索结果里选定后「关联」，关联后可一键去订阅。

### 漫画页（核心）
- 头部：大封面、标题、作者、连载状态、简介（可展开）、在 Kmoe 打开。
- **保存位置条**（同扩展）：存储位置 › 解析后的目录 · EPUB/MOBI · 线路 · 「更改」。
  所有「已下载 / 缺失」状态都相对这个位置和格式计算。
- **章节网格**（移植扩展的交互）：按 单行本 / 番外 / 连载话 分组，吸顶组标题，组全选；
  瓦片显示名称、大小、页数、状态（已下载 ✓ / 下载中 / 排队 / 失败 / 待确认 / 未下载的空心点 / 新）；
  Shift 连选、方向键漫游、Space 选择；工具条：全选可下载 · 选择缺失 · 清空 · 书库检查。
- 底部固定操作栏：已选 n 项 · 总大小 · 额度占比条 · 「开始下载」（朱印主按钮）。
- **追更设置**（侧栏卡片，窄屏在下方）：开关；追踪内容（单行本 / 番外 / 连载话）；格式；存储位置；
  首次订阅策略「仅追新 / 补齐缺失」；保存前显示影响预览（将新增 n 个任务 · 约 x GB，或将取消 n 个等待任务）；
  上次检查 / 下次检查 / 错误信息；「立即检查」。

### 下载
- 分段筛选：全部 / 进行中 / 等待 / 失败 / 已完成（带计数）。
- 行：封面缩略、漫画 · 章节、格式、目标位置；进行中显示进度条、速度、剩余时间；
  等待重试显示原因与「第 n 次重试 · 30 秒后」；失败显示原因与「重试」。
- 批量：暂停 / 继续队列、重试全部失败、清除已完成。

### 设置
分区分三组（桌面左侧子导航带组名，手机顶部横向滚动、组间有分隔线），标题下不放说明文字：
- **Kmoe 账号**：登录（邮箱 + 密码，密码只用一次不保存）、镜像选择、等级 / VIP、免费与 VIP 额度进度条与重置日、刷新、退出。
- **存储位置**：列表（本地目录 / WebDAV），默认位置；编辑：名称、类型、本地子目录（浏览 NAS 挂载的书库目录）
  或 WebDAV 地址 + 账号 + 密码（可显示）+ 目录（可浏览）；命名规则（变量芯片、预设、路径预览）；测试连接。
  底部可导入浏览器扩展导出的配置（WebDAV 服务器变成存储位置，命名规则一并迁移）。
- **下载与更新**：检查间隔、同时下载数、失败自动重试（开关 + 次数）、额度保留（低于多少 MB 暂停队列）、默认格式与线路。
- **通知**：渠道列表（Webhook / Bark / Telegram），每个渠道选择事件，发送测试。
- **Komga 元数据**：Komga 连接与库对应、Bangumi 数据来源（在线 / 离线数据）、写入内容与锁定、下载后自动同步。
- **Bangumi 书单**：Bangumi 用户名、读取状态、同步周期、立即同步。
- **AI**：OpenAI 兼容接口（DeepSeek / OpenRouter / 自定义）、模型、API Key、是否走代理、每月 token 上限。
- **API 与 MCP**：生成 / 轮换 / 撤销 API 令牌（只显示一次）、REST 与 MCP 使用说明（含 Claude Code 一行命令）。
- **网络代理**：出网的 HTTP 代理、Kmoe 是否走代理、测试连接。
- **安全**：修改管理员密码、退出。
- **关于**：版本、运行环境与用户、数据目录，以及各项设置的概况。

## 视觉系统：墨与纸

完全沿用浏览器扩展的设计令牌与组件（`src/styles/theme.css`、`src/components/ui/*`）：
- 暖纸底色、墨色文字、唯一强调色「朱印」`seal`；跟随系统深浅色。
- 朱印只用于：每个页面唯一的主操作、选中态、进度、活动指示。状态色：success / warning / destructive。
  额度条这类「剩多少」的量表用单一墨色，长度本身说明多少，不借用朱印（它和 destructive 色相太近，会显得吃紧）。
- 网点纹理 `tone` 只用于少量装饰（空状态、头部、封面占位）。
- 字体：拉丁字母与数字用 Geist / Geist Mono（Fontsource 打包进镜像，不请求外部字体），中文回退到系统字体
  （苹方、HarmonyOS Sans、MiSans、Noto Sans SC、微软雅黑）。
- 字号：正文 14px，辅助 12px，分区标题 15px semibold，页面标题 22–28px semibold；数字一律 `tabular-nums`；
  路径、规则、令牌用 `font-mono`。行高一律是整数像素（主题里 `text-xs/sm/base/lg` 的行高写成长度而非比例），
  否则 13px 这类字号继承到小数行高，Chrome 把半行距向下取整，图标旁的文字会整体偏上约 1px。
- 标题 `text-wrap: balance`，段落 `text-wrap: pretty`（不让最后一行只剩一个字）。
- 圆角：控件 lg、瓦片 xl、卡片 2xl；嵌套时外圆角 = 内圆角 + 间距（分段控件 10px 外框、3px 内边距、7px 滑块）。
  封面用覆盖在图片上的 10% 黑/白细线描边，不用带色相的边框。
- 手机：页面自己的操作（导入、检查、暂停、存储位置）放在顶栏右侧；AI 助手是 48px 圆形悬浮按钮，
  在标签栏上方 16px；底部栏、标签栏、悬浮按钮都让出 `env(safe-area-inset-bottom)`；输入框 16px 字号，避免 iOS 聚焦时放大。
- 动效（Emil Kowalski 原则）：进入用 `ease-out-strong`，屏上移动用 `ease-in-out-strong`，
  时长 150–300ms（进度条按轮询节奏 1s 线性）；绝不从 scale(0) 开始；尊重「减少动态效果」。
  页面切换淡入上浮、列表 `stagger`、滑动指示器、折叠高度动画、按压 0.96 缩放。
- 文案：简短中文，错误信息说明原因和下一步。

## 技术栈

- 前端：Vite 8 · React 19 · TypeScript 7 · Tailwind CSS 4 · shadcn/ui（Radix Nova）· TanStack Router & Query ·
  zustand · motion · sonner · zod · lucide-react。
- 后端：Bun · `Bun.serve` · `bun:sqlite`（WAL）· zod；共享 `shared/` 的类型与接口契约。
- 部署：单个 Docker 镜像（amd64 / arm64；x86 使用 Bun baseline 构建，兼容不支持 AVX2 的 NAS CPU），
  卷 `/data`（数据库、密钥、封面缓存）与 `/library`（本地书库）。
